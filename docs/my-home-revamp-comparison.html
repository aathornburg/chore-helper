My Home revamp exploration

Three bolder directions for the home model page, each with a more expressive 2D house.

These options move beyond the current safe layout. The goal is to see whether the page should become a cutaway model, a more editorial product board, or a dramatic blueprint-style experience.

Architectural cutaway

Recommended

The 2D house becomes the hero, with the page feeling like a sectional drawing that you can edit. Rooms feel like labeled parts of a model instead of a list of cards, and the details ride beside the house so the layout gets wider and calmer.

Option C

Blueprint theater

This one goes the farthest visually: a dark blueprint surface, glowing linework, and a more dramatic 2D house. It has the most wow factor, but it also departs the most from the rest of the app.
