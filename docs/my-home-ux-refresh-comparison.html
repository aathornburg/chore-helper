My Home UX refresh options

Three directions for making Overview, Floors, and Rooms feel roomier and more intentional. The key tensions: primary button hierarchy, avoiding box-shadow overload, and making the workspace fill more of the browser instead of stopping halfway down the viewport.

Option A

Workspace canvas

Recommended

Keeps the current mental model but gives every view a taller two-column workspace: floor selector on the left, one primary work panel on the right. Main panels get the offset shadow; room rows stay flat inside the Rooms panel.

Option B

Model-first overview

Turns each view into a full-width model board. The 2D house becomes the hero object, with details underneath. This feels more visual and welcoming, but it makes editing workflows a little farther from the selector.

Best fit

Option A is the safest implementation path. It fixes the current complaints while preserving the current tab and floor-selector model.

Most visual

Option B gives the 2D house the most presence and feels friendlier, but it changes the layout rhythm more dramatically.

Most efficient

Option C is strongest for large homes or multiple properties, but it feels more like admin software.
