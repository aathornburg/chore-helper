Cleanly Family Page

Four ways to make Family feel useful, not just administrative.

The current page manages access well, but it does not yet answer the user’s likely question: “Is the household workload clear, fair, and covered?” These concepts range from a light extension of the current page to a full rethink.

A. Additive Hub B. People First C. Fresh Load Board D. Multi-Home Crew

Option A / Safest evolution

Family command center

Build on the current access-management page, but give the top half real household context: who is included, what is pending, who has the most work this week, and whether the household is balanced enough.

Why this works Lowest implementation risk. Keeps the existing member/invite flow. Adds useful rollups without changing the mental model. Watch-outs Still feels like an admin page unless the load summary becomes visually prominent.

Option B / Additive but warmer

People-first roster

Make the page about the people doing the work. Each person gets a compact profile with role, current week workload, next assigned chore, and access controls. Invitations become a smaller side task.

Why this works Feels less sparse immediately. Gives users a reason to visit Family even after setup is complete. Watch-outs Needs chore assignment summaries to feel fully alive. Without that data, cards can become decorative.

Option C / Fresh start

Responsibility board

Start over with the Family page as a household coordination board. Access management is still present, but the page leads with responsibility balance across people and days.

Why this works Most useful if Cleanly’s value is family balance. It turns Family into a living view instead of a settings-adjacent page. Watch-outs Higher implementation effort. Needs careful empty states for single-user households.

Option D / Fresh start for multiple homes

Multi-home crew map

Treat Family as “who has access to which home, and where is the workload landing?” This is strongest for users with a family home plus rentals, cabins, parents’ homes, or other properties.

Why this works Handles the future multi-property story gracefully without making single-home users feel secondary. Watch-outs May be too much for the default single-household user unless the single-home state is very focused.
