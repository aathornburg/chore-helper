Calendar export UX

Export mode should feel like selecting work, not configuring machinery.

These options remove the heavy shadow from Work My Calendar, make the date range explicitly auto-select eligible events, and move the destination calendar later in the flow so users can focus on choosing what goes out.

Option A

Range-first command panel

Recommended. The panel says exactly what happens: pick a range, Clenella selects matching items, then export.
