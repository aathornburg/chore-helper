Households page: 2D floor selection

Three directions for the idea of selecting floors by clicking the actual floor of a 2D house. These are intentionally rough interaction mockups, not final visual design.

A. Elevation-first

The page opens with a simple side view of the house. Users click the actual floor band first, then edit rooms and attributes in a panel. This makes the original 2D house idea the strongest visual signal.

B. Floor-plan-first

Users start inside the selected floor plan. This is better for room-level setup, flooring, pet access, and robot coverage, but the “click the actual floor of the house” idea is less central.
