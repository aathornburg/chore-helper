Month View Chore Styling

Reduce the “bubble inside bubble” feel.

The day tile already provides the container. In month view, chore items can be quieter than cards while still being clickable. I recommend Option 2 or Option 4.

Option 1

Flat clickable rows

Remove the card background entirely. Keep a small hover state so the chore still feels clickable.
