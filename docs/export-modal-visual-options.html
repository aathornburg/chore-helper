Export modal concepts

How should users review Cleanly events before export?

All options keep the same setup controls: export from a Cleanly date range, export to a selected external calendar, then confirm what leaves Cleanly. The difference is how much detail appears first.

A · Direct review

Event review list

A practical list grouped by date. The user sees every eligible event immediately and checks what should be exported.
