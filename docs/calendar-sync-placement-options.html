Where should calendar sync work live?

Settings should hold long-lived rules and connections. Calendar should own the active work of importing, exporting, and approving calendar items.

Recommendation: use Calendar toolbar actions that open focused import/export modals, while keeping owner queue review on the Calendar page.

A · Recommended

Calendar toolbar + focused import/export modals

Put compact sync actions beside Add chore. Import and export each open their own task-focused modal or sheet. Owner queue stays on Calendar, above the calendar grid when pending.
