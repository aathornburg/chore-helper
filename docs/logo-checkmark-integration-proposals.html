Checkmark integration studies

Three ways to make the check feel like part of the calendar itself, using the same Daymark frame so the comparison is about the idea, not the surrounding style.

Concept 1

Event Becomes Check

The event row starts as a normal schedule line, then resolves into the check. It is a little wink: planning and completion are one continuous action.
