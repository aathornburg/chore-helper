My Home UX pass

View-specific comparisons for Overview, Floors, and Rooms

The page should stop feeling like a persistent admin dashboard. Each tab should own its own content, actions should be local to the thing being edited, and the page should feel like a calm home model instead of a configuration wall.

Recommended direction: local edit actions, no global edit mode.

Overview edits home details. Floors edits the selected floor. Rooms edits one room at a time. This removes the duplicate "Done editing" / "Save" problem and prevents overview stats from leaking into every view.
