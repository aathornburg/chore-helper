Households page UX comparison

Designing for one home first

The current page behaves like a multi-property admin dashboard. These alternatives compare ways to make the common single-household case feel direct while preserving the ability to support multiple homes later.

Recommendation: Option 2, with setup checklist cues from Option 3.

It is the smallest product shift with the clearest UX gain: one-household users land directly in "My Home," while multi-household users still get a list/dashboard when it becomes relevant.
