Completed drawer alternatives

Keep completed chores visible, but quiet.

The planned chore cards should stay dominant. These options progressively change the completed treatment from a tiny copy/icon adjustment to larger structural changes. My recommendation is Option 2 or Option 5.

Option 1

Remove the symbol, keep the drawer

Simplest fix. The collapsed state reads as plain text: “2 completed”. It is calm, but slightly less obviously expandable.

30Today
  • Smallest change from current implementation.
  • May be too subtle unless hover/focus is strong.
  • Good if we want almost no visual ceremony.

Option 2

Chevron after the label

Use “2 completed ˅” instead of “> 2 completed”. It reads more like a disclosure control and less like terminal text.

Recommended
30Today
  • Still compact and clearly expandable.
  • Better visual language than leading `>`.
  • Works well with the existing dashed separator and check rows.

Option 3

Muted label with small caret

The drawer becomes more secondary: gray label, green caret. This keeps attention on planned work even more than Option 2.

30Today
  • Very quiet and readable.
  • Does not expose the count in collapsed form unless we add it.
  • Feels more like metadata than a chore item.

Option 4

Pill count, rows on expand

A compact pill makes the count easier to spot. It costs a bit more visual weight, but still much less than completed cards.

30Today
  • Clear status signal.
  • More visual mass than the text treatments.
  • Good if users are missing completed work entirely.

Option 5

Bottom audit strip

Completed chores become a low-priority footer row inside the day. It reads like a summary strip, not another chore.

Recommended
30Today
  • Very clean collapsed state.
  • The left border signals “secondary section” without a bubble.
  • Best if we want a stronger distinction between planned work and history.

Option 6

Day summary action

Completed work is summarized as secondary day metadata. The “View” action opens the drawer or modal list.

30Today
2 completed
  • Most compact while still explicit.
  • Less like a drawer; more like a day-level summary.
  • Could be too small for touch targets unless padded carefully.
